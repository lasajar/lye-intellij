# Lye

LuaJIT-first language support for JetBrains IDEs, powered by the [lye](https://github.com/lde-org/lye) language server.

- Lua file type, syntax highlighting and a **New → Lua File** action
- Language server features through `lye`, downloaded automatically from its [nightly releases](https://github.com/lde-org/lye/releases/tag/nightly)
- `lde` package support: tool window, run configurations and Project view decorations
